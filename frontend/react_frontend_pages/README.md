# Frontend Project Setup (Collaborators)

This project contains the frontend design. If you already have access to the repository and my branch, follow the steps below to run it locally.

---

## Requirements

- [Node.js](https://nodejs.org/) (v18 or above recommended)
- npm (comes with Node.js)

## Setup Instructions


## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

This starts the development server (usually at http://localhost:5173 or as shown in your terminal after you run "npm run dev").

View in browser

Open the URL displayed in the terminal to see the frontend running.
